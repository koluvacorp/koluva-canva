# Koluva Canva 1.0.0

Editor gráfico para Windows. Proyectos y recursos permanecen en el equipo; no requiere cuenta.

## Descarga

- Windows x64: https://github.com/koluvacorp/koluva-canva/releases/download/canva-v1.0.0/KoluvaCanva-1.0.0-Windows-x64-Setup.exe
- Actualizaciones firmadas: https://github.com/koluvacorp/koluva-canva/releases/download/canva-stable/latest.json
- Ficha del producto (ES/EN/PT/FR): [docs/listing.md](docs/listing.md)

## Compilar desde el código

El código fuente no está incluido en este repositorio público. Para una compilación de desarrollo se necesita el repositorio privado autorizado de Koluva Canva y Node.js 24 o superior. La distribución oficial se publica como instalador firmado por manifiesto; el manifiesto incluye tamaño y SHA-256 para que la aplicación verifique la descarga.
